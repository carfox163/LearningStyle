# Learning Styles Quiz｜学习风格在线自测
> Live Demo 在线演示：🔗 https://learnstyle.netlify.app/

一个双语（英文+中文）学习风格在线自测网页，纯前端静态页面，**无需后端、不需要数据库**，浏览器本地完成全部计分运算。
适合英语课堂、心理课、学生自我认知活动使用。



## ✨ 项目功能
1. 📖 **前置知识介绍**：7种学习风格双语科普（Visual视觉 / Auditory听觉 / Verbal言语 / Kinesthetic动觉 / Logical逻辑数理 / Social社交 / Solitary独立独处），附带现代教育学补充说明：学习风格**没有优劣之分**。
2. 📝 **14道双语自测题目**，全部单选，必须全部作答才可以提交。
3. 🧮 **浏览器本地计算**：算出你的**主导学习风格 + 次要学习风格**。
4. 📊 测试结果输出完整解析：英文描述 + 中文解读 + 典型特征 + 实用学习建议。
5. 🔁 重置问卷按钮：一键清空作答、隐藏结果，重新测试。
6. 📱 响应式布局：电脑、手机平板都可以正常浏览使用。
